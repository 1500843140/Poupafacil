🧹 Iniciar controlo financeiro

Quando estiveres pronto para começar com dados reais, podes apagar os movimentos de teste. As despesas fixas, os orçamentos e as metas ficam guardados. Faz uma cópia de segurança antes.

🔒 Cópia de segurança

Guarda os teus movimentos e metas num ficheiro. Importa-o para recuperar os dados noutro telemóvel.

Exporta uma cópia JSON regularmente. Os dados não são sincronizados entre dispositivos.

Os teus dados ficam neste navegador. Se limpares os dados do site ou mudares de telemóvel, podes perdê-los.
