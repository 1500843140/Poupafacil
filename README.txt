POUPAFÁCIL — versão 1.0

Ficheiros: index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png.

Publicação pelo telemóvel usando GitHub Pages:
1. Cria uma conta em github.com e um repositório público chamado poupafacil.
2. Envia os seis ficheiros para a raiz do repositório (Add file > Upload files > Commit changes).
3. Em Settings > Pages, seleciona Deploy from a branch, branch main, pasta /(root), e Save.
4. Aguarda a publicação. O endereço será normalmente https://TEU-UTILIZADOR.github.io/poupafacil/ .
5. Abre esse endereço no Chrome Android e escolhe menu ⋮ > Adicionar ao ecrã principal > Instalar, se disponível.

Atenção: a aplicação guarda dados apenas no navegador do dispositivo, sem sincronização. Faz cópias JSON regularmente. Não tem pagamentos, subscrições nem contas de utilizador. O site deve ser servido por HTTPS (GitHub Pages) para funcionar como PWA.
